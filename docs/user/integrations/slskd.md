# Slskd Integration Guide

## 1. Overview

The Slskd integration enables Soulseek network audio search and download acquisition managed by EchoSync's Download Manager (`services/download_manager.py`).

## 2. Setup & Configuration

1. Ensure Slskd daemon is running with REST API enabled.
2. Enter Slskd host URL and API key in EchoSync Settings.
3. Configure Quality Profiles to set preferred bitrate and file format priorities (FLAC vs MP3).
